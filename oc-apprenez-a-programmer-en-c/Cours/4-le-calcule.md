# Le calcul dans C

## Les opérateurs de base

- addition : +
- soustraction : -
- multilication : *
- division : /
- modulo : %

*Dans le cas de division avec des entiers seule la partie entière sera résultante,
exemple : `5 / 2 = 2`.*

## Les raccoucis

- l'incrémentation : var++;
- la décrémentation : var--;

### Par réaffectation à la variable

- addition : var += 4;
- soustraction : var -= 56;
- multiplication : var *= 3;
- division : var /= 2;
- modulo : var %= 4;

## La bibliothèque mathématique

La bibliothèque standard dispose d'une librairie mathématique, `<math>`.
Cela se met en place par l'inclusion de la bibmliothèque par `#include <math>`.
Pour connaitre son API voi [ici](https://devdocs.io/c/numeric/math).
